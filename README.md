Visit Rwanda is a full stack web application built with ASP.NET Core MVC and Entity Framework Core. It showcases Rwanda’s tourist attractions and investment opportunities in an interactive, user friendly interface, highlighting the beauty and potential of my home country. The project demonstrates practical use of MVC architecture, database integration, and responsive design.

Features:

Display tourist destinations and investment opportunities from a relational database.

Full CRUD operations for managing content.

Responsive UI with Bootstrap, including layout pages and reusable components.

Implements routing, model binding, and dynamic data rendering with Razor Views.

Technologies: C#, ASP.NET Core MVC, Entity Framework Core, SQL Server, Bootstrap, HTML/CSS

Purpose: Developed as a final assignment for ASP.NET Core MVC coursework to showcase Rwanda and demonstrate full-stack web development, database integration, and modern UI design.
